.NET 11 CLI & library

Run .NET apps in isolated Linux containers.

Give DotNetPod a published DLL, a runtime image and a data directory. Manage each instance by name on your local Docker Engine.

Run the sample

Instance lifecycle

From specification to shutdown

run

Start the DLL with its configured limits. Repeating the same specification finds the existing instance.

status

Inspect state and restart count. A readiness marker lets the app signal when it can accept work.

stop / unload

Stop an instance to resume it later. Unload it to remove the container and reuse its data with a replacement.

Operator guide

Inspect your first worker

The sample worker records its runtime version, hostname and Linux resource limits. Compare its reported readiness with the file it writes to the host.
